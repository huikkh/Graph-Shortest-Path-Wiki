# HTML Teaching Slides

- `index.html`：從零理解 Dijkstra 的互動式 HTML 教學簡報（14 張投影片）。
- `content-map.md`：每張投影片與 Wiki 頁面、原始來源的對照表。

## 使用方式

直接以瀏覽器開啟 `index.html`，不需要安裝套件或連線網路。

- `←` / `→`：上一頁／下一頁
- `PageUp` / `PageDown`：切換投影片
- `Home` / `End`：跳到第一頁／最後一頁
- 「全螢幕」：切換整個簡報介面全螢幕（包含上方標題、投影片、底部導覽與進度條）；按 Esc 或再次點擊按鈕退出。
- 第 8 張投影片：按下「下一輪」互動觀察 Dijkstra A–F 範例
- 第 13 張投影片：選擇答案查看小測驗回饋

## 知識來源

簡報內容來自本專案 `wiki/` 的 10 個 Markdown 頁面，來源詳見 `sources/R1.md` 至 `sources/R6.md`。逐頁對照見 `content-map.md`。
