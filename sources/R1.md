# R1 — Cornell CS 2110: 21. Graphs

## 摘要

這份課程教材介紹 Graph 的基本定義及術語，包含 Vertex、Edge、Directed Graph、Undirected Graph、Neighbor、Path、Cycle、邊權重，以及 Adjacency Matrix 和 Adjacency List 兩種表示方式。

## 本 Wiki 使用範圍

- Graph、Vertex、Edge 的定義。
- Directed Graph 與 Undirected Graph 的差異。
- Neighbor、Path、Cycle 的基本概念。
- 邊權重與加權路徑成本。
- Adjacency Matrix、Adjacency List 的表示方式與取捨。

## 不直接泛化的內容

教材以一個 Java `WeightedEdge` 類別作為實作範例，該類別要求權重為非負整數。本 Wiki 僅將此視為該程式範例的實作限制，不把它當成 Weighted Graph 的普遍定義。
