# R4 — Cornell CS 2110: 18. Heaps and Priority Queues

## 來源與用途

Cornell University CS 2110 Fall 2026 Lecture 18，介紹 Priority Queue ADT、以 List 為基礎的實作、Heap 的形狀與順序不變量、陣列表示、插入／取出／查看等操作，以及 Heap 的效能優勢。

原始來源：<https://www.cs.cornell.edu/courses/cs2110/2026fa/lectures/lec18/>

## 本 Wiki 擷取範圍

- Priority Queue 是 ADT；Heap 是其中一種實作方式。
- Min-Priority Queue 依最小 priority 先取出；Dijkstra 將目前距離作為 priority。
- Binary Heap 的 shape invariant 與 heap-order invariant。
- 0-based array representation 的 parent / child 索引關係。
- Min Heap 的 `insert` / Bubble Up、`peekMin`、`extractMin` / Bubble Down。
- 單次 Heap 操作的時間複雜度。
- Priority update 與 Dijkstra 的關係；`decrease_key` 的使用情境另由 R3 支持。

## 來源限制與轉換說明

Cornell 教材主要示範 Max Heap，並以 Min Heap 作為延伸練習。本 Wiki 將其對稱轉換為 Min Heap，明確反轉比較方向，並保留教材對 Priority Queue ADT、Heap 結構與操作的原始概念。教材指出 Dijkstra 需要 priority updates，但未將索引式 `decrease_key` 的完整實作作為本講主體；因此該應用說明同時引用 R3，不把未展示的實作細節歸於 R4。
