# R3 — Cornell CS 2110: 23. Shortest Paths

## 1. 來源摘要

Cornell CS 2110 Fall 2026 第 23 講從無權重圖的 BFS 最短路徑延伸到加權圖，介紹 Dijkstra Algorithm。教材涵蓋頂點的 undiscovered、frontier、settled 狀態，暫定距離與前驅資訊，非負權重條件，Dijkstra invariant，動態最小優先佇列，路徑重建，以及時間與空間複雜度。

## 4. 重要技術處理

1. **非負權重：** 零權重允許；負權重會破壞「最小 Frontier 頂點可安全 settled」的保證。
2. **距離狀態：** Frontier 的 `dist` 是目前最佳候選值；只有 settled 後才是最終最短距離。
3. **優先佇列：** FIFO Queue 無法保證依目前暫定距離取出頂點；需要 Min-Priority Queue。
4. **距離改善：** 若候選距離更小，必須同步更新 `dist`、`prev` 與 PQ 的優先值。
5. **佇列實作：** 正式 Wiki 主虛擬碼採用支援 `decrease_key` 的索引式 Min-Priority Queue；另以文字說明 lazy deletion 是另一種實作，不混合兩者的假設。
6. **提前停止：** 只求單一目的地時，必須等目的頂點被取出並 settled 後才能停止；第一次發現目的頂點不足以保證最短。
7. **圖的方向：** R3 以有向非負加權圖作為教材設定。Wiki 補充說明 Dijkstra 同樣適用於非負權重無向圖；可將無向邊視為兩條反向、權重相同的有向邊。
8. **複雜度：** R3 的 heap-backed dynamic priority queue 與 HashMap 模型得到 expected `O(E log V)`；Wiki 使用較一般的 `O((V+E) log V)` 摘要，並將圖表示法與 PQ 的完整比較保留給 07 頁。
