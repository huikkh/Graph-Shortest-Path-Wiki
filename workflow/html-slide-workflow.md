# HTML 簡報生成與檢查紀錄

日期：2026-11-16

## Workflow

1. **Query Wiki**：以已完成的 10 個 Wiki 頁面為唯一教材知識庫，擷取 Graph、Shortest Path、Dijkstra、Edge Relaxation、Priority Queue、Time Complexity，以及 BFS／Bellman-Ford 比較內容。
2. **Organize**：整理 14 張投影片的教學順序：問題引入 → 基礎概念 → 演算法選擇 → Dijkstra 原理 → 狀態與資料結構 → 逐步範例 → 路徑還原 → Relaxation → Priority Queue 與複雜度 → 演算法比較 → 測驗 → 來源。
3. **Source mapping**：建立 `content-map.md`，逐張記錄引用的 Wiki 頁面及 R1–R6 來源。
4. **Content check**：核對 Wiki 04 的 A–F 圖例、settled 順序、距離更新、最終距離與路徑成本；核對 BFS、Dijkstra、Bellman-Ford 的適用條件與複雜度前提。
5. **Generate**：產生單一 `index.html`，將 CSS、JavaScript、SVG 圖示及互動元件內嵌，避免外部依賴。
6. **Browser check**：以 Chromium + Playwright 載入 HTML；測試上一頁／下一頁、方向鍵與 Home／End、Dijkstra 逐輪控制與重設、小測驗回饋與重設，並檢查頁面執行錯誤及桌面／手機版溢位。

## 第 11 頁複雜度說明版面修正（2026-11-16）

- 問題：第 11 頁的複雜度補充說明在手機或較矮視窗中可能與右側複雜度卡片內容重疊。
- 原因：雙欄區塊使用彈性高度，窄螢幕下內容被壓縮，後續說明框仍接續排版，導致視覺重疊。
- 修正：縮短補充文字；在窄螢幕或較矮視窗將兩張卡片改為單欄自然高度排列，允許投影片垂直捲動；調整補充框字級與內距。
- 驗證：以 390×844、600×800、768×600、768×1024、1365×768、1440×900、1920×1080 檢查卡片、補充框及來源列的上下界，未發現重疊。
